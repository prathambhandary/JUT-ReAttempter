# Contributing to JUT ReAttempter

First off, thank you for considering contributing to JUT ReAttempter!

Whether you're fixing a typo, improving the UI, optimizing the backend, or adding a new feature, every contribution helps make the project better for future students.

---

## Before You Start

Please:

- Search existing issues before opening a new one.
- Open an issue before starting large features or major refactors.
- Keep pull requests focused on a single change whenever possible.

---

## Ways to Contribute

You can contribute by:

- Fixing bugs
- Improving performance
- Improving accessibility
- Enhancing the user interface
- Writing or improving documentation
- Refactoring code
- Adding tests
- Reporting issues
- Suggesting new features

---

## Development Setup

Clone the repository

```bash
git clone https://github.com/<username>/JUT-ReAttempter.git
cd JUT-ReAttempter
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Visit

```
http://127.0.0.1:5000
```

---

## Coding Style

Please try to keep code consistent with the existing codebase.

### Python

- Follow PEP 8 where practical.
- Use descriptive variable names.
- Keep functions small and focused.
- Avoid unnecessary dependencies.

### HTML / CSS

- Keep the interface clean and responsive.
- Match the existing design language.
- Prefer semantic HTML.

### JavaScript

- Write readable, modular code.
- Avoid global variables whenever possible.
- Comment only when the code isn't self-explanatory.

---

## Pull Requests

Before opening a pull request, make sure:

- [ ] The application runs successfully.
- [ ] Existing functionality still works.
- [ ] Your changes are limited to the intended feature or fix.
- [ ] You have updated documentation if necessary.
- [ ] You have tested your changes.

Provide a clear description of:

- What changed
- Why it changed
- Any screenshots (for UI changes)

---

## Reporting Bugs

When reporting a bug, please include:

- Operating System
- Browser
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Screenshots (if applicable)

---

## Feature Requests

Feature requests are always welcome.

When suggesting one, explain:

- The problem you're trying to solve
- Your proposed solution
- Any alternative ideas you've considered

---

## Questions

If you're unsure whether something belongs in the project, feel free to open a discussion or issue before starting work.

---

## Code of Conduct

Please be respectful and constructive.

Everyone is welcome regardless of experience level.

---

## Project Philosophy

JUT ReAttempter exists for one reason:

> To help students revise previous JUT papers through a modern, fast, and familiar practice experience.

When contributing, please keep the project:

- Lightweight
- Fast
- Easy to use
- Privacy-friendly
- Open source
