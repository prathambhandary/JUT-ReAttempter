# Security Policy

## Supported Versions

JUT ReAttempter is currently maintained on the latest release only.

| Version | Supported |
| ------- | :-------: |
| Latest Release | ✅ |
| Older Releases | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub issue.**

Instead, report it privately by contacting the project maintainer.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any suggested mitigation (optional)

Every legitimate report will be acknowledged, investigated, and resolved as quickly as possible.

---

## Scope

This policy applies to vulnerabilities affecting the JUT ReAttempter codebase, including:

- Authentication or authorization issues
- Session management
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- SQL Injection
- Command Injection
- File Upload vulnerabilities
- Remote Code Execution
- Sensitive information disclosure
- Dependency vulnerabilities
- Denial-of-Service vectors

---

## Responsible Disclosure

Please allow reasonable time for a fix before publicly disclosing any vulnerability.

We appreciate responsible disclosure that helps keep the project and its users secure.

---

## Out of Scope

The following are generally considered out of scope unless they demonstrate a real security impact:

- Missing HTTP security headers
- Version disclosure
- Minor UI or UX bugs
- Browser-specific rendering issues
- Performance issues without a security impact
- Social engineering attacks
- Vulnerabilities in third-party services not maintained by this project

---

## Third-Party Dependencies

JUT ReAttempter relies on several open-source libraries and services.

If a vulnerability originates from a third-party dependency, please report it to both this project and the upstream maintainers when appropriate.

---

## Security Philosophy

Security is an ongoing process, not a one-time feature.

When contributing, please prioritize:

- Principle of least privilege
- Secure defaults
- Input validation
- Minimal data collection
- Privacy by design

---

Thank you for helping make JUT ReAttempter safer for everyone.
For security-related inquiries, contact **security@firewave.in**.
