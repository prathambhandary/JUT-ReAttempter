Question No:25

The function f : N → N given by is

1 ) Injective 2 ) Surjective
3 ) Bijective 4 ) Many-one

Your Option: 1

Correct Option: 3

Score:4/-1 0.00

Detailed Answer: Suppose f ( x 1 ) = f ( x 2 ) .
Note that, if x 1 is odd and x 2 is even, then we will have x 1 + 1 = x 2 - 1 , i.e., x 2 - x 1 = 2 which is impossible. Similarly, the possibility of x 1 being even and x 2 being odd can also be ruled out, using the similar argument. Therefore, both x 1 and x 2 must be either odd or even. Suppose both x 1 and x 2 are odd. Then, f x 1 = f x 2 ⇒ x 1 + 1 = x 2 + 1 ⇒ x 1 = x 2 . Similarly, if both x 1 and x 2 are even, then also f x 1 = f x 2 ⇒ x 1 - 1 = x 2 - 1 ⇒ x 1 = x 2 .Thus, f is one-one. Also, any odd number 2 r + 1 in the codomain N is the image of 2 r + 2 in the domain N and any even number 2 r in the codomain N is the image of 2 r - 1 in the domain N . Thus, f is onto.
