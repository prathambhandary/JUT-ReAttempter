3 ) 1170           4 ) 2500

Your Option: 1

Correct Option: 3

n ( A U B ) = n ( A ) + n ( B ) - n ( A ꓵ B )

⇒ 3170 - 2000 ≤ n ( A ꓵ B )

Thus the least value of n ( A ꓵ B ) is 1170
Hence the least number of consumers who liked both the products is 1170.
