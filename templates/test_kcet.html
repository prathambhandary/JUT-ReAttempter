General instructions

Paper structure: 60 questions from one subject only, each with four options and a single correct answer.

  • Save & Next saves your response and moves on. An answer is only evaluated if it was saved.
  • Clear Response removes your selected answer for the current question.
  • Mark for Review & Next flags a question to revisit. If you'd selected an answer before marking, it still counts as answered.
  • Use Previous / Next or the palette on the right to move between questions.
  • The palette colour-codes every question: green (answered), red (visited, not answered), purple (marked for review), white (not visited).
  • You cannot switch to another subject or start another test until you submit this one or the timer hits zero.
  • The test auto-submits the instant the timer hits zero — there's no extension.

Marking scheme: +1 for every correct answer. 0 for a wrong or unattempted answer — there is no negative marking.
